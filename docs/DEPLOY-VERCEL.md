# دليل النشر على Vercel — مجانًا بالكامل (Vercel Hobby + Neon Free)

> الحالة بعد التجهيز (`bb265e1` فما بعده): الكود **جاهز للنشر على Vercel كما هو** —
> لا حاجة لتعديل أي شيء إضافي. هذا الدليل يغطي: إنشاء قاعدة البيانات المجانية،
> نقل بياناتك الحقيقية، ربط Vercel، ومتغيرات البيئة.

---

## 0) لماذا هذا التركيبة؟ (صادق ومختصر)

| المكوّن | الخيار المجاني | الحد | ملاحظة صادقة |
|---|---|---|---|
| الاستضافة | **Vercel Pro** | 20$/شهر | **لو العميل بيدفع مقابل استخدام النظام: Pro من أول يوم — قرار تجاري/قانوني وليس تقنيًا.** شروط Hobby تقول «غير تجاري»؛ Hobby مقبول فقط للتجربة الذاتية قبل التعاقد |
| قاعدة البيانات | **Neon Free** | 0.5GB تخزين | بياناتك الحالية أقل من 1MB — سعة كافية لسنوات. لا تحتاج بطاقة ائتمان |

## 1) إنشاء قاعدة البيانات على Neon (5 دقائق)

1. افتح <https://neon.tech> → سجّل حسابًا مجانيًا (GitHub أو Google — **بدون بطاقة**).
2. New Project → اختر Region: **Frankfurt (EU Central)** — الأقرب لمصر (أقل تأخيرًا).
3. بعد الإنشاء، من Dashboard انسخ **Connection string** (يبدو هكذا):
   ```
   postgresql://user:pass@ep-xxx-pooler.eu-central-1.aws.neon.tech/neondb
   ```
   - **استخدم النسخة الموسومة Pooled** (تحتوي `-pooler` في اسم المضيف) — إلزامية
     مع serverless لتجنب نفاد الاتصالات.
4. أضف في نهاية الرابط: `?pgbouncer=true&connection_limit=1&sslmode=require`
   — هذه هي `DATABASE_URL` النهائية.

---

## 2) نقل بياناتك الحقيقية (من جهازك، مرة واحدة)

إن كانت لديك نسخة من أرشيف بياناتك الأصلية `db/custom.db` (SQLite — نسخة خارجية
من نظامك السابق، فالأرشيف داخل بيئة التشغيل قد لا يكون متاحاً دائماً)، فسكريبت
النقل جاهز ويعمل مع أي PostgreSQL (اختُبر مع Postgres المحلي — نفس الأمر مع Neon):

```bash
# من داخل مجلد المشروع على جهازك:
DATABASE_URL="postgresql://...neon...?pgbouncer=true&connection_limit=1&sslmode=require" \
  bunx prisma migrate deploy          # 1) إنشاء كل الجداول

DATABASE_URL="postgresql://...neon...?pgbouncer=true&connection_limit=1&sslmode=require" \
  bun scripts/migrate-sqlite-to-postgres.ts   # 2) نقل المنتجات/العملاء/الفواتير/المخزون

# 3) تحقق: يجب أن يطبع SUCCESS و 0 discrepancies (نفس تقرير التطابق الذي يظهر محليًا)
```

> ملاحظة: لو طبّقت `migrate-sqlite-to-postgres.ts` أكثر من مرة على نفس القاعدة،
> استخدم نسخة نظيفة (Neon → Delete branch → إنشاء من جديد) لأن السكريبت يفترض
> قاعدة فارغة مع `--reset` محليًا فقط.

---

## 3) رفع الكود وربط Vercel (10 دقائق)

1. ارفع المشروع إلى مستودع **GitHub** خاص/سري.
2. <https://vercel.com> → Sign up with GitHub — **اختر الخطة حسب الحالة**: عميل مدفوع ⇒ **Pro (20$/شهر) من أول يوم** (متطلب شروط الاستخدام، مش «تحسين لاحق»)؛ تجربة ذاتية قبل التعاقد فقط ⇒ Hobby المجانية.
3. **Add New… → Project** → اختر المستودع → Import.
4. Vercel يكتشف Next.js تلقائيًا. **لا تغيّر إعدادات البناء** — سكريبت البناء
   يعمل على المنصتين (نسخ standalone تجري فقط عند وجود المجلد محليًا).
5. قبل الضغط على Deploy: افتح **Environment Variables** وأضف:

| الاسم | القيمة | ملاحظة |
|---|---|---|
| `DATABASE_URL` | رابط Neon المجمّع + `?pgbouncer=true&connection_limit=1&sslmode=require` | Production + Preview |
| `AUTH_SECRET` | نص عشوائي طويل | ولّده بـ: `openssl rand -base64 48` |

6. **Deploy** — انتظر انتهاء البناء (2–3 دقائق).

## 4) أول تشغيل وتفعيل الأوفلاين (مهم!)

بعد فتح رابط Vercel من متصفح جهاز الكاشير:

1. **زيارة أولى أونلاين**: سجّل الدخول وافتح **نقطة البيع** مرة واحدة —
   الـ Service Worker (v6) يخزّن **كل ملفات الكود** (61 ملفًا) وsnapshot البيانات.
2. من هنا وأي فصل للإنترنت يترك التطبيق يعمل: بيع/بحث/سلة بشارة «بدون اتصال»،
   والمبيعات تُزامَن تلقائيًا عند عودة الشبكة (مفتاح Idempotency يمنع التكرار).
3. للتحقق: DevTools → Application → Service Workers (Status: activated) و
   Cache Storage (tijara-v6-assets ≈ 61 عنصرًا).

## 5) ما الذي يتغير على Vercel مقارنة بالخادم المحلي؟ (سلوك متوقع لا خطأ)

- **بارد أول طلب**: Neon تُغلَق تلقائيًا بعد خمول — أول طلب بعدها يستغرق
  ~1–2 ثانية. صفحة نقطة البيع تُفتح فورًا من كاش الـ SW وتُحدَّث خلفيةً.
- **لا سكريبتات تشغيل/نسخ احتياطي محلي**: النسخ الاحتياطي = تصدير دوري من
  شاشة التقارير أو `pg_dump` بنفس رابط Neon شهريًا (أو الترقية لاحقًا لـ
  Point-in-Time Restore).
- **سرّ الجلسة**: أي تعديل لـ `AUTH_SECRET` في Vercel يخرج جميع المستخدمين
  (سلوك أمني مقصود — المبيعات المعلّقة تبقى محفوظة وتُرسَل بعد إعادة الدخول).
- **HTTPS + دومين**: يأتيان مجانًا (`*.vercel.app`). دومين خاص لاحقًا ~10$/سنة
  (اختياري تمامًا).
